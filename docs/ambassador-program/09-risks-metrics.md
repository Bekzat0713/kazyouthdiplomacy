# Амбассадорская программа — Риски и метрики эффективности

Версия: 1.0

## 1. Риски и способы устранения

### Организационные

| Риск | Вероятность | Митигация |
|---|---|---|
| Миграция провалится: из 370 верифицируются немногие | средняя | ссылка + личный призыв Алиби в WhatsApp; 3 волны напоминаний; дедлайн 3–4 недели; верификация за 3 минуты; пилот на лояльной группе до массового запуска. Целевой ориентир из концепции: 200–250 — это успех, а не провал |
| Нет готовых тимлидов/координаторов на старте | высокая | назначить ДО миграции из проверенного ядра; первые 2 месяца — «исполняющие обязанности», утверждение по результатам |
| Тимлиды перегорят (бесплатная управленческая работа) | высокая | ≤ 20 человек на тимлида жестко; сертификаты и рекомендательные письма именно за управленческий опыт; закрытые встречи с партнерами только для тимлидов+; ротация раз в семестр по желанию |
| Система умрет от бюрократии (отчеты ради отчетов) | средняя | отчет амбассадора — 2 минуты, 3 вопроса из 5 кнопочные; тимлид/координатор ничего не пишут руками — только смотрят сводки; раз в квартал пересматривать вопросы |
| Все держится на Алиби (как сейчас) | высокая | это главный смысл проекта: права и данные развязаны по ролям; правило — Алиби не решает то, что может решить координатор |
| Обещали больше, чем можем (ожидание «вступил = стажировка») | средняя | аккуратные формулировки на сайте и в боте (уже заложены); правило «баллы = приоритет, не гарантия» прописано в правилах сообщества |

### Продуктовые и технические

| Риск | Вероятность | Митигация |
|---|---|---|
| Длинная анкета → бросают на середине | средняя | 14 вопросов, 3 опциональных, 4 кнопочных; прогресс-бар; сохранение прогресса в БД; напоминание через 24 ч; метрика drop-off по шагам с первого дня |
| Накрутка баллов | средняя | весь раздел «защита от фиктивной активности» в 05: QR, проверка человеком, потолки, ledger, выборочные проверки, штрафы |
| Telegram заблокируют аккаунт бота / сбой API | низкая | бот не единственный канал (канал + группы остаются); БД — источник правды, бот лишь интерфейс; экспорт контактов доступен head |
| Render перезапускает сервис — теряются диалоги | высокая (по опыту проекта) | состояние FSM в PostgreSQL, не в памяти (заложено в архитектуре) |
| Утечка ПД (данные несовершеннолетних!) | низкая, ущерб высокий | доступ по веткам; экспорт только head; логи без ПД; согласия фиксируются; для гранта — оформить политику обработки ПД документом на сайте |
| server.js (8115 строк) станет неподдерживаемым | высокая | весь новый код в отдельных модулях bot/ routes/ lib/ (заложено в ТЗ) |

### Юридические

- **Несовершеннолетние (16–17 лет):** согласие законного представителя
  обязательно (в MVP — контакт + подтверждение, желательно довести до
  письменной формы для грантовых требований); их ПД видят только координатор+.
- **Персональные данные:** опубликовать политику обработки ПД на сайте
  (требование закона РК «О персональных данных и их защите»); собирать только
  нужное; право на удаление профиля по запросу (ручная процедура в MVP).
- **Ambassador ID:** оформление подчеркнуто «членское» (номер в профиле бота),
  без пластиковых карт с фото и госсимволикой.

## 2. Метрики эффективности

### Воронка набора (смотрим еженедельно)

| Метрика | Формула | Ориентир |
|---|---|---|
| Переходы в бот | старты по source | рост |
| Конверсия в отправленную заявку | submitted / стартов | ≥ 40% |
| Drop-off анкеты по шагам | по amb_bot_states | нет шага с потерей > 15% |
| Скорость рассмотрения | медиана submitted → решение | ≤ 7 дней |
| Конверсия отбора | accepted / submitted | наблюдаем (качество источников) |
| Эффективность источников | конверсия по source | сравнение каналов |

### Миграция (разовая кампания)

- % верифицированных из 370 к дедлайну (успех ≥ 55%, т.е. 200+);
- % завершивших сценарий из начавших (≥ 85% — сценарий короткий);
- время прохождения (медиана ≤ 5 минут).

### Здоровье сообщества (ежемесячно — главные метрики программы)

| Метрика | Формула | Ориентир |
|---|---|---|
| **Доля активных** | activity_status='active' / всех | ≥ 60% |
| Сдача еженедельных отчетов | сдано / должно | ≥ 70% |
| Выполнение заданий | approved / взятых | ≥ 75% |
| Скорость проверки отчетов | медиана submitted → review | ≤ 3 дней |
| Отток | ушедшие в reserve/alumni за месяц | ≤ 5%/мес |
| Прохождение испытательного | trainee → ambassador за 30–45 дней | ≥ 70% |
| Кадровый резерв | участников со ступенью senior+ | ≥ 30 (хватает на ротацию тимлидов) |
| Равномерность потоков | разброс активности между потоками | нет потока-аутсайдера ×2 |

### Ценность для участников (ежеквартально — для грантовых заявок)

- посещаемость мероприятий (подтвержденная QR);
- пройденные модули Core Skills (v2 — автоматически, MVP — по заданиям career);
- заполненные профили Career GPS;
- **карьерные результаты:** стажировки/работа, полученные амбассадорами
  (вводится вручную в профиль — это витринная метрика для грантов);
- выданные сертификаты и рекомендательные письма;
- NPS сообщества (опрос в боте раз в квартал: «порекомендуешь программу
  другу? 0–10» — одна кнопка, две минуты на всех).

### Метрики управляемости (для Алиби)

- время Алиби на рутину (субъективно, но главный KPI проекта: цель —
  с «весь день в WhatsApp» до «2 часа в неделю на дашборд и решения»);
- % решений, принятых без эскалации до head;
- скорость реакции тимлидов на needs_help (медиана ≤ 48 ч).

Все метрики, кроме NPS и карьерных результатов, считаются автоматически из
таблиц `amb_*` — дашборд в admin-панели их и показывает (см. 04).
