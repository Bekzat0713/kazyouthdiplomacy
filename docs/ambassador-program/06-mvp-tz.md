# Амбассадорская программа — MVP: объем и техническое задание

Версия: 1.0. Стек: существующий (Node 20, Express 5, PostgreSQL, Render,
vanilla JS в `public/`). Новая зависимость: `grammy` (Telegram-бот),
`qrcode` (генерация QR в админке). Больше ничего не добавляем.

## 1. Границы MVP

**Входит:** страница «Стать амбассадором»; бот — регистрация, верификация
миграции, меню, задания, мероприятия с QR, баллы, еженедельные отчеты,
уведомления, 2 языка; админ-панель — дашборд, заявки, участники, задания,
мероприятия, отчеты; ручное распределение с подсказками; cron-автоматика
статусов и напоминаний.

**Не входит (v2/v3):** мобильное приложение; автораспределение;
автосертификаты; рейтинги; интеграция данных Career GPS/Core Skills (только
ссылки); английский язык; кабинет работодателя; алгоритм подбора вакансий.

## 2. Структура кода

```

  flows/registration.js   — FSM анкеты (сценарий A)
```

`app.use('/api/amb', require('./routes/amb-admin'))` и `require('./bot')`.

## 3. Конфигурация (env на Render)

```
TG_BOT_TOKEN=...            — токен от @BotFather
TG_WEBHOOK_SECRET=...       — случайная строка; путь /api/tg/webhook/<secret>
                              + заголовок X-Telegram-Bot-Api-Secret-Token
TG_ADMIN_CHAT_ID=...        — чат для служебных уведомлений (новые заявки)
APP_BASE_URL=https://...    — для ссылок из бота на сайт
```

Webhook ставится при старте: `bot.api.setWebhook(APP_BASE_URL + path, {secret_token})`.

## 4. Этапы реализации (порядок жесткий, каждый этап проверяем и деплоим)

| Этап | Содержимое | Готовность = |
|---|---|---|
| 1. Каркас | grammY + webhook + /start + выбор языка + amb_bot_states + DDL всех таблиц + сиды треков | бот отвечает на проде, таблицы созданы |
| 2. Регистрация | сценарий A целиком (анкета, треки, вводное задание, согласия, minor-ветка) | заявка появляется в БД со статусом submitted |
| 3. Заявки в админке | amb-applications.html + решения + уведомления кандидату | полный цикл: подача → решение → сообщение в бот |
| 4. Распределение и меню | amb-people.html, назначение потока/команды, главное меню бота, профиль | принятый видит команду и профиль |
| 5. Задания и баллы | amb-tasks (админ + бот), проверка, ledger, потолки | цикл задание → отчет → баллы работает |
| 6. Отчеты и мероприятия | weekly-flow + cron, events + QR, amb-reports | понедельничная рассылка и QR-чекин работают |
| 7. Автоматика и дашборд | все cron-правила статусов, amb-admin дашборд, эскалации | статусы двигаются сами, метрики на экране |
| 8. Миграция | сценарий B, массовый прием, страница сайта, тексты KZ вычитаны | пилот: 10–20 реальных амбассадоров прошли верификацию |
| Запуск | ссылка в WhatsApp-группу, дедлайн верификации, мониторинг | — |

Рекомендация по запуску: **пилот на одной будущей команде (15–20 человек)**
до массовой рассылки на 370 — соберете обратную связь по анкете и текстам.

## 5. Нефункциональные требования

- Ответ бота на любое действие ≤ 2 сек (все запросы к БД индексированы).
- Все действия бота идемпотентны (двойное нажатие кнопки не дублирует
  запись — UNIQUE-ограничения из схемы это гарантируют).
- Тексты — только из bot/i18n.js, в коде текстов нет.
- Ошибка в одном апдейте не роняет обработчик (try/catch на верхнем уровне,
  лог + вежливое «что-то пошло не так»).
- ПД: экспорт только head; в логи не пишем телефоны/email.
- Бэкапы БД — стандартные снапшоты Render (проверить, что включены).

## 6. Оценка объема

При реализации здесь, со мной: этапы 1–3 ≈ 2–3 рабочих сессии, 4–7 ≈ 3–4 сессии,
8 + вычитка казахских текстов носителем + пилот ≈ 1–2 сессии и календарная
неделя пилота. Для внешнего разработчика уровня middle: ~3–4 недели фултайм.
Стоимость инфраструктуры: 0 ₸ сверх текущего Render (бот и панель живут в том
же сервисе; отдельный токен BotFather бесплатен).

## 7. Критерии приемки MVP (чек-лист)

- [ ] Новый человек проходит регистрацию с телефона за ≤ 7 минут на обоих языках
- [ ] Заявка видна в панели со всеми данными и вводным заданием
- [ ] Решение по заявке доходит в бот ≤ 5 сек
- [ ] Принятый получает поток/команду и видит их в профиле
- [ ] Полный цикл задания с начислением баллов и отклонением работает
- [ ] Понедельничная рассылка отчетов уходит всем активным
- [ ] needs_help мгновенно приходит тимлиду
- [ ] QR-чекин на тестовом мероприятии начисляет баллы
- [ ] Тимлид не может открыть данные чужой команды (проверить руками)
- [ ] Несовершеннолетний не проходит без контакта представителя
- [ ] Рестарт сервера не теряет незавершенную анкету
