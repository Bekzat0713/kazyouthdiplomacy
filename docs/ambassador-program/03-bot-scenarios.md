# Амбассадорская программа — Пользовательские сценарии Telegram-бота

Версия: 1.0 (MVP). Тексты сообщений — в `07-bot-texts.md`, здесь — логика шагов.

Обозначения: `[Кнопка]` — inline-кнопка, `{Меню}` — кнопка reply-клавиатуры,
`state:` — состояние FSM в `amb_bot_states`.

## A. Регистрация нового кандидата

Вход: `/start` или deep-link `t.me/<bot>?start=site|inst|wa|friend`
(параметр → `amb_profiles.source`).

```
A1. Приветствие + выбор языка          state: reg:lang
    [Қазақша] [Русский]
A2. Что такое программа (1 экран, коротко) + [Начать регистрацию] [Подробнее]
    «Подробнее» → 3 карточки: что получаешь / что ожидается / как проходит отбор
A3. Согласия                           state: reg:consents
    4 пункта чекбоксами-переключателями:
    ☑ обработка персональных данных (ссылка на политику на сайте)
    ☑ правила сообщества   ☑ кодекс поведения   ☑ получение сообщений
    [Подтверждаю все] — активна только когда отмечены все 4.
    Время каждого согласия → amb_profiles.consents (JSONB).
A4. Анкета (пошагово, 1 вопрос = 1 сообщение)   state: reg:q_<имя_поля>
    1) Имя и фамилия                    (текст)
    2) Дата рождения                    (текст ДД.ММ.ГГГГ, валидация)
       → если < 18: доп. шаг — контакт законного представителя +
         чекбокс «Представитель ознакомлен и согласен» → is_minor=true
    3) Город                            (текст; топ-10 городов кнопками + «Другой»)
    4) Телефон                          [📱 Поделиться контактом] — только так,
                                        ручной ввод не принимается
    5) Email                            (текст, валидация)
    6) Место учебы/работы               (текст)
    7) Специальность                    (текст)
    8) Уровень образования              (кнопки: школа/бакалавриат/магистратура/
                                         докторантура/другое)
    9) Языки                            (текст свободно)
    10) Навыки                          (текст, [Пропустить])
    11) Опыт волонтерства/проектов      (текст, [Пропустить])
    12) Мотивация: почему хочешь стать амбассадором (текст, мин. 100 символов)
    13) Сколько часов в неделю готов уделять (кнопки: 1–3 / 4–6 / 7+)
    14) Ссылки на соцсети               (текст, [Пропустить])
    Прогресс показывается: «Вопрос 5 из 14».
    Цель — 5–7 минут: 3 вопроса опциональные, 4 — кнопочные.
A5. Выбор направлений                  state: reg:track_primary → reg:track_extra
    Сначала ОДНО основное (список 11 кнопками),
    затем до ДВУХ дополнительных (мультивыбор, [Готово], [Без дополнительных]).
A6. Вводное задание                    state: reg:intro_choose → reg:intro_submit
    Кандидат выбирает ОДИН формат:
    [🎥 Видео до 60 сек о мотивации]  → ждем video/video_note, проверка длительности
    [💡 Идея молодежного мероприятия] → текст ≥ 200 символов
    [✍️ Небольшой информационный пост] → текст ≥ 200 символов
    [🧩 Проблема молодежи, которую хочу решить] → текст ≥ 200 символов
    [📝 Короткий тест о KazYouthDiplomacy] → 5 вопросов с вариантами,
        засчитывается при ≥ 4 правильных (иначе одна пересдача)
A7. Подтверждение и отправка
    Сводка анкеты → [Отправить заявку] [Изменить ответы]
    → amb_applications.status = 'submitted', уведомление в админ-чат/панель.
A8. Финал: «Заявка отправлена, рассмотрим до N дней» + что будет дальше.
```

Обработка обрывов: состояние в БД; при возврате «Продолжим с вопроса 7?»
[Продолжить] [Начать заново]. Cron: через 24 ч незавершенной анкеты — одно
напоминание (не больше одного, не спамим).

## B. Верификация действующего амбассадора (миграция 370)

Вход: deep-link `?start=migrate` (публикуется в WhatsApp-группе).

```
B1. Язык → B2. «Ты уже в команде — подтверди участие, займет 3 минуты»
B3. Согласия (как A3 — юридически нужны заново)
B4. Телефон [📱 Поделиться контактом]
B5. Короткая анкета: имя, дата рождения, город, email,
    место учебы/работы, специальность (6 вопросов вместо 14)
B6. Выбор направлений (как A5)
B7. Мини-тест: 5 вопросов о деятельности организации (порог 3/5, одна пересдача)
B8. «Готов продолжать участие?» [Да, я в деле] [Хочу в резерв]
B9. Профиль создан: program_role = 'ambassador', activity_status = 'active',
    номер KYD-XXXX присвоен, заявка kind='migration', status='accepted'.
    Сообщение: «Скоро назначим тебе поток и тимлида».
```

Не прошедшие до дедлайна: cron переводит связанные с WhatsApp-списком записи…
— в MVP проще: у кого нет профиля в боте к дате X, тех считаем «резервом»
организационно (в системе их просто нет; список WhatsApp сверяется вручную один раз).

## C. Главное меню (после приема)

Reply-клавиатура (постоянная):

```
{👤 Профиль}      {🧭 Направления}
{👥 Моя команда}  {📋 Задания}
{📅 Мероприятия}  {⭐ Мои баллы}
{📝 Отчет}        {🚀 Возможности}
{❓ Помощь}
```

- **Профиль:** имя, KYD-номер, статус (ступень), поток, команда, тимлид,
  баллы, счетчики (заданий выполнено, мероприятий посещено).
- **Направления:** текущие треки, [Изменить] (не чаще 1 раза в месяц).
- **Моя команда:** имя тимлида (+username), имя координатора, список команды
  (имена), ссылка на Telegram-группу команды, если есть.
- **Возможности:** в MVP — кнопки-ссылки на Career GPS (сайт) и Core Skills +
  анонсы, которые публикует админ. В v2 — персональная выдача.
- **Помощь:** FAQ + [Написать тимлиду] (даёт username) + [Связаться с админом].

До приема меню усеченное: {📄 Моя заявка} {❓ Помощь}.

## D. Задания

```
D1. {📋 Задания} → две вкладки-кнопки: [Доступные] [Мои]
D2. Доступные: список карточек (title, категория, баллы, дедлайн,
    осталось мест). Фильтр по аудитории задания (all/поток/команда/трек).
D3. Карточка → полное описание + ожидаемый результат + форма отчета
    [✅ Взять задание] — проверка лимита участников и дубля.
D4. После взятия: задание в «Мои». Напоминание за 24 ч до дедлайна (cron).
D5. [📤 Сдать отчет] → бот просит контент по report_format
    (текст / фото / файл / ссылка) → подтверждение → status='submitted'
    → уведомление тимлиду в бот: «N отчетов ждут проверки».
D6. Решение проверяющего приходит в бот:
    ✅ «Принято, +12 баллов. Комментарий: …»
    ❌ «Возвращено на доработку: …» → можно сдать повторно (1 раз)
D7. Дедлайн прошел, отчета нет → status='expired', вежливое уведомление.
```

## E. Еженедельный отчет

```
E1. Cron: понедельник 10:00 по Астане — всем с program_role >= trainee:
    «Привет! Короткий отчет за неделю — 5 вопросов, 2 минуты» [Начать]
E2. Вопросы (state: weekly:q1..q5):
    1) Что делал(а) по программе на этой неделе? (текст / [Ничего])
    2) В каких мероприятиях участвовал(а)? (текст / [Не участвовал(а)])
    3) Какие навыки развивал(а)? (текст / [Пропустить])
    4) Нужна ли помощь? [Все ок] / текст → needs_help=true
    5) Готов(а) участвовать на следующей неделе? [Да] [Частично] [Нет]
E3. needs_help=true → мгновенное уведомление тимлиду с текстом.
E4. Среда 18:00 — одно напоминание тем, кто не сдал.
E5. 4 сданных отчета подряд → автоначисление «стабильная активность» +10
    (source_type='weekly_streak').
E6. 3 недели без отчетов подряд → activity_status='unresponsive' +
    уведомление тимлиду.
```

## F. Мероприятия и QR-подтверждение

```
F1. {📅 Мероприятия} → список ближайших (по аудитории) → карточка →
    [Зарегистрироваться] / [Отменить регистрацию]
F2. Напоминание за день до мероприятия (cron).
F3. На площадке организатор показывает QR (генерируется в админке):
    ссылка t.me/<bot>?start=ev_<qr_token>
F4. Скан → бот проверяет: мероприятие идет сегодня (±1 день), участник
    зарегистрирован (или регистрирует на месте) → attended=true,
    confirmed_via='qr' → «Участие подтверждено, +5 баллов!»
F5. Ручное подтверждение — тимлидом/админом в панели (confirmed_via='manual').
```

## G. Уведомления о статусах (бот → участник)

| Событие | Сообщение |
|---|---|
| Заявка взята в работу | «Твоя заявка на рассмотрении» |
| needs_revision | «Нужно доработать: <комментарий>» + [Доработать] |
| Приглашение на интервью | «Приглашаем на короткое интервью» + детали |
| Принят | Поздравление + KYD-номер + что дальше (вводное обучение) |
| Резерв / отклонен | Вежливый текст + при резерве «вернемся при наборе» |
| Назначены поток/команда | Поток, тимлид (+username), координатор |
| Испытательный срок пройден | «Ты теперь амбассадор!» |
| Повышение / понижение | Текст с причиной |
| Начисление/списание баллов | Всегда с причиной из ledger |

## H. Служебные команды

- `/start` — контекстный вход (deep-links выше);
- `/menu` — показать главное меню заново;
- `/lang` — сменить язык;
- `/cancel` — прервать текущий сценарий (анкету — с сохранением прогресса);
- `/help` — то же, что {❓ Помощь}.

## I. Защита от злоупотреблений в боте

- Rate-limit на webhook-обработчик (существующий express-rate-limit не трогаем,
  у Telegram свой IP-диапазон — лимитируем по telegram_id в коде: ≤ 20 действий/мин).
- Валидация всех callback_data (никогда не доверять id из кнопки — проверять права).
- Один telegram_id = один профиль (UNIQUE), повторная регистрация невозможна.
- QR-токены одноразовые по смыслу не нужны, но привязаны к дате мероприятия.
